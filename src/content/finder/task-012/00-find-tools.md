# 不知道工具名稱？從你要完成的任務開始

很多人不是先知道：

> 「我要用 PDF Page Reorder。」

真正的想法通常是：

> 「我的 PDF 頁面順序亂了。」

或：

> 「這張圖片太大上傳不了。」

或：

> 「老師給我 A、B+ 和學分，我要算 GPA。」

所以這一頁不是另一份 79 個工具的清單。

它的工作是：

> **把自然語言任務，轉成正確的工具入口。**

如果你已經知道工具名稱，直接到 [全部工具](/tools/) 搜尋最快。

如果你知道自己是老師、學生、設計師或開發者，但還沒確定任務，可以到 [依使用情境找工具](/for/)。

如果你的任務有多個步驟，例如「整理報告 → 壓圖片 → 合併PDF → 產QR」，可以直接看 [工作流程工具包](/workflows/)。

## 第二步：你想做什麼動作？

### 合併
- 多份 PDF → [PDF 合併](/tools/merge-pdf/)
- 多張圖片 → 一份 PDF → [圖片轉 PDF](/tools/images-to-pdf/)

### 拆開
- PDF 按頁／範圍拆分 → [PDF 拆分](/tools/split-pdf/)
- 只拿指定頁 → [擷取 PDF 頁面](/tools/extract-pdf-pages/)

### 刪除
- 刪 PDF 頁 → [刪除 PDF 頁面](/tools/delete-pdf-pages/)
- 刪文字空白行 → [移除空白行](/tools/remove-empty-lines/)
- 刪重複文字行 → [移除重複行](/tools/remove-duplicate-lines/)

### 壓縮
- 圖片 → [圖片壓縮](/tools/image-compressor/)
- PDF → [PDF 壓縮](/tools/pdf-compressor/)

壓縮不是保證一定更小。原始檔已高度最佳化時，輸出可能差異有限。

### 轉換
- PNG → JPG
- JPG → PNG
- JPG → WebP
- WebP → JPG
- PDF → 圖片
- 圖片 → PDF
- CSV ↔ JSON
- URL encode/decode
- Base64 encode/decode
- Unix timestamp ↔ 日期

如果你不確定「轉換後會失去什麼」，先看對應指南，而不是只看副檔名。

### 計算
- 百分比
- 平均
- 加權平均
- GPA
- 日期差
- 年齡
- 工作日
- 標準差
- PR / Z / T

正式制度型結果仍要回到學校、銀行、雇主或官方規則核對。

### 隨機
- 數字
- 姓名
- 分組
- 點名
- 轉盤
- 骰子

如果活動涉及獎品、公平性或不得重複中選，先確認抽樣規則。

### 視覺化
- 比較類別 → 長條圖
- 少量部分占整體 → 圓餅圖
- 流程／決策 → 流程圖
- 幾何草稿 → 2D CAD

## 這個找工具頁如何運作？

頁面可以提供互動式 Finder：

1. 選輸入類型。
2. 選動作。
3. 可選使用情境。
4. 立即顯示 1–5 個最相關工具。
5. 顯示一個「為什麼推薦」。
6. 顯示必要的限制或指南。

但搜尋／篩選狀態不應建立大量可索引 URL。

例如：

> 不要為 `?type=pdf&action=split&audience=student` 建一個新的SEO頁面。

互動狀態可以留在瀏覽器端；真正需要 Google 索引的是：
- 本頁
- 工具頁
- 分類頁
- Audience頁
- Workflow
- 高價值指南

## 找不到完全符合的工具？

FunnyTools 不應因為搜尋不到，就推薦一個其實不會完成任務的工具。

如果目前沒有：
- OCR
- Office檔案完整編輯
- 動態QR代管
- 專業CAD
- 密碼管理器
- 專業統計軟體

Finder 應明確說：

> **目前沒有直接工具。**

再提供最接近的指南或工作流程。

這比硬把不相關工具塞給使用者更有價值。
