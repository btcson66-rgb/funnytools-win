# 圖片尺寸怎麼改才不變形？像素、長寬比、比例鎖定與放大模糊完整指南

把一張 1600×900 圖片硬改成 800×800，很容易出現人臉變胖、Logo 被壓扁、圓形變橢圓。

這不是單純「畫質不好」，而是：

> **原本 16:9 的長寬比被強迫變成 1:1。**

> **速答：圖片尺寸怎麼改才不變形？**  
> 打開「維持比例／鎖定長寬比」，只修改寬度或高度其中一邊，另一邊依比例自動計算。例如 1600×900 是 16:9，縮成 800px 寬時應約為 800×450，而不是 800×800。若平台要求正方形，應先 Crop 成 1:1，再 Resize；直接把長方形拉成正方形會變形。

## 一、什麼是像素尺寸？

`1920 × 1080`

代表：

- 寬 1920 pixels；
- 高 1080 pixels。

總像素：

`1920 × 1080 = 2,073,600`

約 2.07MP。

## 二、什麼是長寬比？

長寬比：

`width : height`

常見：

- 1920×1080 → 16:9
- 1600×1200 → 4:3
- 1000×1000 → 1:1

只要縮放時維持原比例，幾何形狀就不會被拉伸。

## 三、1600×900 縮成 800 寬應該多高？

原比例：

`1600 / 900 = 1.777...`

新寬 800：

`800 / 1.777... ≈ 450`

所以應該是：

`800 × 450`

## 四、為什麼 800×800 會變形？

因為原本 16:9 被硬改成 1:1。

這不是 Crop，而是 Stretch。

結果可能：
- 人臉變寬；
- Logo 變扁；
- 圓形變橢圓；
- 字體比例變怪。

## 五、FunnyTools Image Resizer 的現行限制

目前 Image Resizer：

- 可輸入寬高；
- 可維持比例；
- 20MB 輸入上限；
- 40 百萬像素輸入上限；
- 每一個輸出 dimension 必須 1～8000；
- 產生新檔，不修改原圖。

所以若不想變形：

> 維持比例。

## 六、平台要求 500×500怎麼辦？

如果原圖不是正方形，不要直接 Resize 成 500×500。

正確流程：

1. Crop 成 1:1；
2. 調整構圖；
3. 再 Resize 500×500；
4. 檢查人臉和重要內容。

## 七、縮小圖片會怎樣？

例如：

`4000×3000 → 1000×750`

原始多個像素會重新取樣成較少像素。

通常：

- 檔案會更小；
- 更適合螢幕；
- 下載更快。

但：
- 細節減少；
- 小字可能變糊。

## 八、放大圖片會怎樣？

例如：

`200×150 → 2000×1500`

軟體只能透過 interpolation 推算新像素。

它不會恢復：
- 原本不存在的毛髮；
- 已經模糊的文字；
- 失焦細節。

所以：

> **圖片變大不等於真實解析度提升。**

## 九、為什麼放大 Logo 很糊？

如果只有 200px 寬的 PNG，硬放到 2000px，原本像素被大量插值。

Logo 更適合：

> 找 SVG / AI / PDF 等向量來源。

## 十、網站圖片真的需要 4000px 嗎？

如果版面最大顯示 1200 CSS pixels，卻載入 5000px 圖片，通常浪費下載。

但 Retina / 高 DPR 螢幕可能需要更高解析副本。

網站應搭配：

- `srcset`;
- responsive images;
- 正確 width/height。

## 十一、DPI 和像素尺寸不是同一件事

螢幕最直接看：

> pixel width / height。

把一張 1200×800 圖片 metadata 從 72 DPI 改成 300 DPI：

> 不會增加任何像素細節。

DPI/PPI 更常和實體印刷尺寸相關。

## 十二、列印尺寸怎麼估？

圖片寬 3000px。

以 300ppi：

`3000 / 300 = 10 inches`

約 25.4cm。

但實際可接受 PPI 仍依：
- 觀看距離；
- 印刷品質；
- 用途

不同。

## 十三、比例和尺寸要分開理解

平台要求：

- 1:1；
- 至少 1080px。

這代表：

### 比例
正方形。

### 像素尺寸
至少 1080×1080。

兩個條件都要符合。

## 十四、Resize 和 Compress 可以一起用嗎？

可以，而且很常見。

例如：

`4032×3024 JPG 6MB`

→ Crop  
→ Resize 1600×1200  
→ JPG/WebP  
→ Compress

通常比只壓品質更合理。

## 十五、先改寬還是高？

看目標。

如果網站只限制 max-width：

> 先輸入寬。

如果是大頭貼 600×600：

> 先 Crop 1:1，再指定 600×600。

如果是直式封面：

> 依高度和比例決定。

## 十六、40 百萬像素有多大？

例如：

`8000 × 5000 = 40,000,000`

FunnyTools 目前會擋更大的輸入，以降低瀏覽器記憶體風險。

檔案只有 8MB 不代表解碼後很小。

## 十七、輸出最大 8000px代表什麼？

現行每一個輸出 dimension 最大 8000。

例如：

- 8000×5000 可以；
- 12000×8000 不行。

這是產品現行防護，不是影像格式理論上限。

## 十八、常見錯誤

### 錯誤 1：16:9硬改1:1
會變形。

### 錯誤 2：以為放大就會變清楚
不會。

### 錯誤 3：平台要正方形卻不 Crop
人臉可能拉長。

### 錯誤 4：網站只顯示800px卻載6000px
浪費 bytes。

### 錯誤 5：把 DPI 當魔法
不會增加像素。
