# PDF 太大怎麼壓縮到 10MB、5MB、2MB？上傳限制與畫質完整指南

申請系統、學校作業、公司報帳、履歷平台或政府網站常會遇到同一個問題：**PDF 明明只有幾頁，卻有 20MB、40MB，平台只收 10MB、5MB，甚至 2MB。**

很多人第一個反應是一直找「PDF 壓縮」，但按了幾次只從 28MB 變成 27MB。原因通常不是工具壞掉，而是 **PDF 變大的原因不同，真正有效的縮檔方式也不同**。

> **速答：PDF 太大怎麼壓？**  
> 先確認平台的實際限制，再判斷 PDF 是「文字／向量型」還是「高解析掃描／照片型」。文字型 PDF 可以先嘗試結構最佳化；掃描型 PDF 的容量通常主要來自圖片，需要降低原始圖片尺寸、品質或頁數。FunnyTools 的 PDF 壓縮工具目前做的是**瀏覽器本機 PDF 結構重新整理，不會重新採樣圖片，也不保證每份 PDF 都會變小**。如果目標是從 40MB 壓到 5MB，而檔案主要是高解析掃描，通常必須從圖片來源下手。

## 一、先確認平台到底限制什麼

不要看到「上傳失敗」就先壓縮。平台可能限制的是：

- 單一檔案不得超過 2MB、5MB、10MB 或 20MB；
- 全部附件總容量；
- PDF 頁數；
- 只能上傳一份 PDF；
- 不接受密碼保護 PDF；
- 檔案格式或檔名規則。

如果限制是「單檔 10MB」，建議不要把成品控制在 9.99MB，而是留一些安全空間，例如 8～9MB。不同系統對 MB 的計算、驗證與重新封裝方式可能不同。

## 二、為什麼只有 5 頁的 PDF 也能有 50MB？

PDF 是一種容器，不是「一頁固定多少 KB」的格式。它可能包含：

- 可搜尋文字；
- 向量線條；
- 內嵌字型；
- JPG／PNG；
- 高解析掃描影像；
- 透明圖層；
- 表單；
- 註解；
- 附件；
- 重複資源；
- 編輯軟體留下的額外物件。

20 頁純文字報告可能不到 1MB；5 張手機原尺寸照片直接做成 PDF，卻可能超過 50MB。

所以第一個判斷不是「幾頁」，而是：

> **這幾頁裡裝的是什麼？**

## 三、先分辨：文字型 PDF 還是掃描型 PDF

### 文字型 PDF

通常由 Word、PowerPoint、Google Docs 或排版軟體直接匯出。你可以用滑鼠選取句子、搜尋文字。

容量來源可能是：

- 未最佳化結構；
- 內嵌字型；
- 大型圖片；
- 重複物件。

這種檔案可以先試 FunnyTools 的 [PDF 壓縮工具](/tools/pdf-compressor/)。

### 掃描型 PDF

如果每一頁看起來像照片，文字無法選取，放大會看到掃描顆粒，通常是影像型 PDF。

這種檔案的大部分容量往往是：

> **每一頁的圖片像素。**

例如一頁 A4 掃成 4000×5600 像素、全彩、高品質，20 頁自然可能非常大。

## 四、FunnyTools PDF 壓縮工具真正做什麼？

目前 FunnyTools PDF Compressor 的定位是：

- 在瀏覽器本機處理；
- 重新寫入／整理 PDF 結構；
- 嘗試降低未最佳化的物件與結構負擔；
- **不會降低內嵌圖片解析度**；
- **不保證輸出一定比原檔小**；
- 目前單檔輸入上限為 **40MB**。

這種方式的優點是：不會為了硬壓檔案而直接把掃描文字壓糊。

缺點也很明確：如果 PDF 90% 容量都來自高解析照片，結構最佳化可能只省一點點。

## 五、40MB 壓到 10MB，代表要減少多少？

40MB → 10MB，等於要減少：

`(40 - 10) / 40 = 75%`

這是非常大的降幅。

如果原檔主要是文字與未最佳化結構，可能有機會大幅縮小；如果是每頁高解析彩色掃描，就通常需要真正降低圖片資料量。

FunnyTools 不能承諾：

> 「任何 40MB PDF 都能壓到 10MB。」

這種承諾本身就不合理。

## 六、10MB 壓到 5MB、5MB 壓到 2MB呢？

- 10MB → 5MB：需要減少 50%；
- 5MB → 2MB：需要減少 60%。

如果結構最佳化只能從 10MB 降到 9.2MB，就表示檔案大小主要不在 PDF 結構。

此時應改問：

> 是否有高解析圖片？是否有不需要的頁面？能不能從來源檔重新匯出？

## 七、掃描 PDF 最有效的方法：回到圖片來源

如果你還有原始照片或掃描圖，通常可以：

1. 保留原始檔，不直接覆蓋。
2. 裁掉桌面、黑邊、多餘背景。
3. 降低過大的圖片尺寸。
4. 依用途調整 JPG 品質。
5. 再用 [圖片轉 PDF](/tools/images-to-pdf/) 重建。
6. 打開新 PDF，檢查小字、簽名、QR Code、表格。
7. 若仍略大，再做一次結構最佳化。

這通常比「大 PDF → 壓縮 → 再壓縮 → 再壓縮」有效。

## 八、圖片到底要縮到多小？

沒有一個所有用途通用的數值。

如果只是螢幕閱讀，通常不需要保留手機原始 48MP 或 108MP 圖片。

如果是 A4 一般文件，重點應是：

- 小字仍清楚；
- 簽名仍可辨識；
- QR Code／條碼仍能掃；
- 表格線與小數點不糊；
- 列印需求仍符合接收方規範。

若是證件、法律文件、工程圖或細小文字文件，應優先保留可讀性，不要只追求 MB 數字。

## 九、先刪掉不需要的頁，比壓縮更有效

如果 80 頁 PDF 實際只要交：

- 第 1 頁；
- 第 12～18 頁；
- 第 80 頁；

不要先壓整份 80 頁。

先用 [擷取 PDF 頁面](/tools/extract-pdf-pages/) 只保留真正需要的內容，通常更有效，也能減少不必要個資。

延伸閱讀：[PDF 只存其中幾頁怎麼做？](/guides/extract-specific-pages-from-pdf/)

## 十、可以拆成兩個 PDF 上傳嗎？

只有平台允許時才可以。

如果官方寫：

> 「請合併為單一 PDF 上傳。」

就不應為了檔案大小自行拆成 part1 / part2。

如果系統允許多附件，依文件邏輯拆分可能比把所有頁面壓得很糊更好。

## 十一、PDF → JPG → PDF 可以大幅變小，但代價很大

這個方法確實有時能大幅縮小，尤其原本就是影像型 PDF。

但可能失去：

- 可搜尋文字；
- 可複製文字；
- 向量圖；
- 連結；
- 書籤；
- 表單；
- 無障礙標籤；
- 數位簽章驗證能力。

所以它適合：

> 本來就是掃描圖片，且接收方只要求「視覺可讀的 PDF」。

不適合把原生文字型 PDF 全部點陣化。

## 十二、壓縮後為什麼反而變大？

可能原因：

- 原 PDF 已經高度最佳化；
- 新工具重新封裝後產生額外結構；
- 原來的物件壓縮方式更有效；
- 字型與資源重新寫入方式不同。

因此壓縮後要比較：

- 原始大小；
- 輸出大小；
- 可讀性。

如果輸出比較大，沒有必要拿新檔取代原檔。

## 十三、超過 FunnyTools 40MB 上限怎麼辦？

目前 PDF Compressor 會阻止超過 40MB 的輸入。

此時可依情況：

- 回 Word／PowerPoint 來源重新匯出；
- 從原始掃描圖片降低尺寸；
- 先用其他可靠方式只保留必要頁面；
- 改用更適合大型 PDF 的桌面軟體。

瀏覽器本機工具並不適合所有數百 MB 文件。

## 十四、手機壓大型 PDF 為什麼容易卡住？

本機 PDF 工具通常需要：

1. 讀取整個原始檔；
2. 解析 PDF；
3. 在記憶體建立新 PDF；
4. 產生下載檔。

實際記憶體需求可能遠大於「檔案只有 30MB」。

手機瀏覽器分頁記憶體有限，可能出現：

- 卡住；
- 分頁重載；
- Safari／Chrome 直接關閉。

正式大檔建議改用電腦。

## 十五、數位簽章 PDF 要特別小心

對使用憑證數位簽署的 PDF，重新輸出、刪頁、合併、壓縮或重建都可能改變文件內容與簽章驗證狀態。

正確做法：

- 保留原始簽署版；
- 不要直接覆蓋；
- 若需要修改，從未簽署來源重新處理；
- 依接收機關規則重新簽署。

「看得到簽名圖樣」不等於數位簽章仍有效。

## 十六、壓縮後一定要做的 7 個檢查

1. **頁數**：有沒有少頁？
2. **頁序**：順序是否正確？
3. **小字**：放大後還看得清嗎？
4. **簽章**：外觀是否完整？
5. **QR Code／條碼**：還能掃嗎？
6. **表單／連結**：若原本需要，是否仍可用？
7. **檔案大小**：真的低於平台限制嗎？

## 十七、常見錯誤

### 錯誤 1：不知道限制就一直壓
先看平台規則。

### 錯誤 2：掃描 PDF 只做結構壓縮，卻期待縮小 90%
影像才是主要容量。

### 錯誤 3：把文字 PDF 全部轉 JPG
會失去文件功能與搜尋文字。

### 錯誤 4：壓完不開檔檢查
「下載成功」不等於文件完整。

### 錯誤 5：直接覆蓋唯一原檔
永遠保留原始版本。

### 錯誤 6：為了 2MB 把小字壓到不可讀
上傳成功但內容無法辨識，反而失去目的。

## 十八、快速決策表

| 狀況 | 優先做法 |
|---|---|
| 文字 PDF 稍大 | 結構最佳化 |
| 高解析掃描 PDF | 降低圖片尺寸／品質後重建 |
| 只需少數頁 | 先擷取指定頁 |
| 平台可多附件 | 合理拆分 |
| 數位簽署 PDF | 保留原始簽署版，不任意重建 |
| 手機處理大檔卡住 | 改用電腦 |
| 壓縮後更大 | 保留原檔 |

## 十九、FAQ

### FunnyTools 可以保證把 PDF 壓到 10MB 嗎？
不能。工具做的是結構最佳化，不會重採樣圖片，實際降幅取決於原始 PDF。

### PDF 壓縮一定會變糊嗎？
FunnyTools 目前不降低內嵌圖片解析度，因此不以犧牲圖片畫質換取大小；但其他會重採樣圖片的壓縮方式可能讓畫質下降。

### 為什麼掃描 PDF 特別大？
因為每一頁可能就是一張高解析照片。

### 怎麼把 PDF 壓到 2MB？
先移除不必要頁面，再針對圖片資料量下手。內容很多的文件可能無法在維持可讀性的前提下合理壓到 2MB。

### PDF 轉 JPG 再轉回 PDF 可以嗎？
可以，但會失去可搜尋文字、連結、表單等文件特性，只適合明確知道代價的影像型文件。

### PDF 超過 40MB 怎麼辦？
目前 FunnyTools PDF Compressor 無法處理，建議回來源檔重新輸出、降低掃描圖片尺寸，或使用適合大型文件的桌面工具。
